# Dormant custody and re-admission

Current read access, current Writer authority and custody of accepted old work are separate facts. Keep the original historical-source owner when a signed ACL removes the Writer. The session follows authenticated checkpoints without permitting ordinary issuance or automatic replacement under the absent role.

Re-admission gives the new current session only its current ACL authority. The same store continues its monotone device sequence and still holds exact unresolved source bytes and proof. The policy can rebase, expire, or expose manual review according to the existing operation contract; missing frontier and `old-incarnation` classification alone never settle an operation. Preserve a durable visible result for policy resolution.

The settlement plan owns shared source contexts. Each retained source refers to an exact digest; the context contains its signed anchor and anchor-bound ACL. The source verifier reopens these bytes under the already authenticated fixed creator and pinned genesis. The mechanical store checks correspondence and preserves bytes, while the verifier grants historical authority only. The original atomic retirement rewrite releases a context only when no retained source refers to it.

One source context is bounded at 73,900 canonical bytes by the existing 8,192-byte anchor, 64-byte signature and 65,536-byte ACL limits. It counts in the existing issuance image and rewrite bounds. SQLite stores a versioned canonical/base64 carrier inside its existing text field, so the admission reserve must also charge its exact native representation before accepting work. Connecting custody to publication is gated on that reserve; a successful storage round trip alone does not prove finishability.

Verify an unsent accepted operation and unresolved manual review across removal, persisted reopen, readmission and later cleanup. Keep a stale session handle and delayed signed request as controls: both must remain fenced. Verify full removal and role-only removal separately, because retaining a non-Writer ACL member does not prove the absent-member case.
