# Causal correction and final verification

For each confirmed unintended owner, an independent RED author writes a focused
ownership regression. GREEN fixes release at the natural owner, preserving
retention policy and correctness. Prefer deterministic count/ownership assertions
to exact heap sizes. Verify affected integration behavior and obtain independent
implementation review before comparing a repeated bounded probe.

Finally run the same fixed unprofiled 64-writer/100-transition diagnostic with
unchanged heap settings and assertions. Report baseline and final slopes,
correctness/recovery, unexplained growth, and acceptance limits. If all measured
growth is intentional, do not invent a cleanup to improve the number: report it
and still verify the unchanged full workload.
